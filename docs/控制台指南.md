# 鱼缸控制台指南

> 浏览器管理面板：`cd console && node server.mjs` → 打开 `http://127.0.0.1:3201`。
> 零依赖（node:http 单文件服务），只绑 127.0.0.1 回环，写请求需 Origin + `X-Fish-Console: 1` 双校验（防浏览器扩展 CSRF）。

## 九个页面

| 页面 | 管什么 |
|---|---|
| **总览** | 鱼在线状态、巡逻/熔断、今日说话/思考统计、每小时分布、最近唤醒 |
| **唤醒记录** | 每次唤醒一行：几条消息、耗时、结果（sent/silent/skipped/timeout/error）、原因、token 消耗；按日期/群/结果筛选 |
| **审阅** | 行话候选转正/驳回、记忆候选迁入 core.md、词条复审下架——**人工闸门**，鱼自己只能写候选 |
| **记忆** | core.md（长期记忆，红线 60 行）+ 行话库生效态总览 |
| **自动化任务** | 「▶ 立即学习」「✎ 写今日日记」按钮（真实模型任务，运行中 409 防重入）；学习积压卡（游标/日志行数/未学）与日记积压卡（今日已写/素材/连续记录/缺口）；日记列表点开阅读、悬停 × 删除（删前归档留痕） |
| **配置** | 五组表单（白名单人格 / 限额 / 作息 / 模型 / 卫生门禁）+ 两段式应用（改表单 → 预览 diff → 30 秒确认 → 自动备份 10 份）；学习/日记任务各有独立模型三件套（供应商/模型/档位，带订阅型置灰标注） |
| **人格卡** | persona.md 在线编辑，即存即生效（唤醒现读盘），自动 .bak |
| **测试发送** | 手写一句话让鱼真发到群（走完整出站链路）——验证"你的手 → 她的嘴" |
| **表情包** | 库内图片网格（使用次数排序/搜索/上传/删除进回收站/一键恢复）；使用次数来自发言记录聚合 |
| **运维** | 适配器重启、模式切换、操作流水、会话清理（防漏网兜底，预览恒 0 属正常——秒回会话不落库） |

## 配置页要点

- **模型三件套**（聊天 / 学习任务 / 日记任务各自独立）：供应商下拉来自 ZCode 的 provider 配置 + 订阅型条目（置灰留位，ZCode 开放无头支持后自动可选）；换供应商模型列表跟着变；不配走默认（GLM-5.3-Flash/low）
- **额度**：思考额度（次/天）与说话额度（条/天）按**本地日**归零（午夜 0 点）；私聊独立额度
- **改完生效**： patrols 配置大部分需重启适配器（应用后界面会提示 restartPending）——运维页点重启

## 任务按钮的真实成本

「立即学习」与「写今日日记」触发的是**真实模型会话**（协议路线，mode:edit 自动批读写、危险工具三层拦截）：学习读约 400 行积压、日记写一篇吐槽，Flash 档单次几毛钱。任务 prompt 的真源在 `console/tasks-manual.json`（历史定时任务快照），模型在配置页切换。

## 安全边界（与鱼一致的纪律）

- 控制台是**你的**工具：所有审阅闸门（记忆/行话）、删除操作（日记归档、表情回收站）都留痕可溯
- 控制台**不持有**模型 API key——它只是编排者，模型调用全走 ZCode CLI 的会话协议
- 文件端点全部白名单正则 + 路径防穿越（日记名 `^\d{4}-\d{2}-\d{2}\.md$`、表情名扩展名白名单）
- 归档留痕在鱼够不到的地方：删除日记 → `fish-adapter/logs/diary-deleted.jsonl`；丢弃消息 → `dropped.jsonl`

## 常见问题

| 症状 | 处置 |
|---|---|
| 打不开 3201 | 控制台没跑（`node server.mjs`）或端口被占（启动会明确报 EADDRINUSE） |
| 配置应用后没生效 | 需重启适配器（运维页）——额度/模型/作息等启动时读一次 |
| 预览 diff 显示 ** 无变化 | secret 字段显示 **** 保持原样即不改 |
| 顶栏"适配器 离线" | 适配器进程没跑——鱼上线脚本或 watchdog 会拉；也可以运维页手动 |
